# Archive

Superseded documents, kept because they say how this got here. **Nothing in this
directory is current.** Where it disagrees with the code or with `docs/`, it is wrong.

- **`workbench_spec.md`** — what the workbench had to do, written before it existed. Its
  purpose and its four stages survive in [`../design.md`](../design.md); its layout does
  not. It describes a workbench living inside the one project it worked on, which is no
  longer how this is built or used.
- **`UI_design.md`** — how the board was meant to look, before it was built.
- **`NOTES.md`** — decisions taken while building, with the reasoning, and the questions
  that were open at the time. The most useful of the three, and the one most likely to be
  stale: it was a working record, not documentation.
